> This mod is no longer being developed or maintained. 
> There will be no further updates, new features, of bug fixes.

**Purchase Requirement:** To access all features, you must purchase a house. Salesheet is located on the wall right next to the entrance door in house, you need to have at least 19990MK to buy a house.

## Features
- Brand-new, custom-made house in Loppe (replaces the old abandoned mansion).
- Graphics and some other useful settings.
- Reworked assembly system for body parts of Satsuma.
- New garage with a pit.
- Working wardrobe doors in player's room.
- New terrace, rooms and sauna.
- Custom electricity system and bills.
- Fully openable cabinets in kitchen.
- Working fridge, telephone, mailbox, computer and TV.
- Battery charger, parts catalog and additional tools.
- Story progression and many other features.
- Importing your own images for posters, flag, paintings and wallpapers.

## Reworked Satsuma Assembly System
- Attach Satsuma body parts to walls with an assembly icon.
- Save the state of the assembled parts.
- Tools for building and repairing Satsuma are provided on the dashboard.
- Enable dashboard lights, charge car batteries with a charger, and order tuning parts via a catalog.

## Custom Electricity System and Bills
- Each electrical appliance in the house consumes electricity.
- Track electricity usage on the fuse table in the closet.
- Pay electricity bills every 6 real hours to maintain power.
- Use the mailbox near the driveway to pay bills (ensure items are moved).
- Electricity is independent of the player’s main house. Turning off electricity in the main house does not affect this house.
- A master switch on the fuse table controls electricity for the entire house. Set it to "1" for power and "0" for no power.
- Higher electricity consumption speeds up the timer for power cut-off.

## Customizable Decorations
- Import custom images for posters, flags, paintings and wallpapers.
- Place files in the assets folder `(steamapps\common\My Summer Car\Mods\Assets\LoppeHouse)`.
- File names must follow this format:

```text
Flag.png
GaragePoster.png
HousePoster1.png
HousePoster2.png
WallLivingroom.png
WallPlayer.png
WallHall.png
Painting1.png to Painting5.png
```

## Graphics and Settings
- Enhanced graphics and various useful settings.
- Change textures in-game using the mod settings menu.﻿﻿
- Reload save file using the mod settings menu (save file resets automatically after starting a new game).
